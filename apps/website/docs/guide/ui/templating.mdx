Prefer JSX. Interpolated values escape. Use `class`, not `className`.

```tsx twoslash
const Hello = ({ name }: { name: string }) => <p class="lede">Hello, {name}</p>;
```

Use `h()` when a file cannot use the JSX runtime. See [Without JSX](/guide/recipes/h).

## Events

Event props are lowercase native names: `onclick`, `onchange`, `onsubmit`. Use a plain function. You do not need a special action wrapper on the client.

```tsx twoslash
import { atom } from "ilha";

const Counter = () => {
  const count = atom(0);
  return (
    <button type="button" onclick={() => count.update((n) => n + 1)}>
      {count}
    </button>
  );
};
```

Disclosure and dialog elements report their own state changes: `ontoggle` and `onbeforetoggle` on `<details>`, `onclose` and `oncancel` on `<dialog>`. The handler's `currentTarget` carries the typed element:

```tsx twoslash
const Panel = () => (
  <details
    ontoggle={(e) => {
      console.log(e.currentTarget.open);
    }}
  >
    <summary>More</summary>
    <p>Details</p>
  </details>
);
```

On a server island, bind `oxidejs` `action`s with `.with(...)` on event props so SSR can serialize frame sentinels. Plain client islands keep plain handlers. See [Server islands](/guide/routing/server-islands).

## Touch the DOM node

Pass `ref` to read the live element. You receive the node on mount and `null` on unmount:

```tsx twoslash
const Field = () => (
  <input
    type="text"
    ref={(el) => {
      el?.focus();
    }}
  />
);
```

Treat the `null` call as cleanup: disconnect observers and release library handles there. Do not keep the node past `null`; a rerender may replace it. See [Render and hydrate](/guide/ui/render) for a full vanilla-library recipe.

## Lists

Atoms hold data. Map an array during render:

```tsx twoslash
import { atom } from "ilha";

type Item = { id: string; text: string };

const List = () => {
  const items = atom<Item[]>([{ id: "1", text: "One" }]);
  return (
    <ul>
      {items().map((item) => (
        <li key={item.id}>{item.text}</li>
      ))}
    </ul>
  );
};
```

When `items` changes, the component reruns and morphs the list. Keys on `li` reuse DOM nodes when the array shifts. Components accept `key` the same way with no extra prop type — `JSX.IntrinsicAttributes` covers it.

For live server lists, paint a Stream into a hole. See [Streams](/guide/ui/streams).

## Keep user state across rerenders

Rerenders morph the live DOM instead of replacing it. Form values, focus, caret position, and a user-opened `<details>` or `<dialog>` survive by default — the morph keeps `open` unless your render sets it explicitly.

Reused components, keyed rows, and atom holes stay attached while their parent rerenders. An `<iframe>`, a playing `<video>`, a scrolled container, or a custom element inside them keeps its state. An empty `contenteditable` element keeps what the user typed; give it children when you want the render to control its content.

When a render must not overwrite an attribute that code outside the render changed, mark it with `data-morph-preserve`:

```tsx twoslash
const Card = () => (
  <div
    data-morph-preserve="title"
    title="rendered"
    onmouseenter={(e) => {
      e.currentTarget.title = "seen";
    }}
  >
    content
  </div>
);
```

The handler writes a live `title`, and later rerenders keep it. List attribute names separated by spaces.

Add the `children` token when code outside the render owns an element's content, such as a chart or editor library:

```tsx twoslash
const Chart = () => (
  <div class="chart" data-morph-preserve="children">
    <p>Loading chart…</p>
  </div>
);
```

The first paint inserts the placeholder. Later rerenders still sync the element's attributes, but they leave its children alone. Tokens combine, as in `data-morph-preserve="title children"`. Code can also add the attribute to a live element at runtime to claim it.

## Raw HTML

Interpolated strings escape. You wrap pre-rendered markup in `unsafe()` to paint it as HTML:

```tsx twoslash
import { unsafe } from "ilha";

const Badge = ({ svg }: { svg: string }) => <span>{unsafe(svg)}</span>;
```

Use it for markup you built or sanitized yourself: SVG from an external library, Markdown rendered to HTML, embed codes. Never pass untrusted user input. Inserted scripts do not run. Event attributes still apply. The URL and style sanitizers that guard JSX props are skipped. Sanitize anything you did not author.
