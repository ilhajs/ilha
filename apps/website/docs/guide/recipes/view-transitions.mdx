---
title: View transitions
---

You animate between UI states with the browser View Transition API. Ilha does not wrap it. Call `document.startViewTransition()` and update an atom inside the callback.

```tsx twoslash
import { atom } from "ilha";

export default function Card() {
  const checked = atom(false);

  const toggle = () => {
    document.startViewTransition(() => {
      checked.update((value) => !value);
    });
  };

  return (
    <button
      type="button"
      class="card"
      onclick={toggle}
      style="view-transition-name: card"
    >
      {checked() ? "Checked" : "Unchecked"}
    </button>
  );
}
```

The callback must update state synchronously so the browser can snapshot both sides of the transition.
