---
title: Oxlint plugin
description: Optional lint rules that ship with @ilha/router.
---

`@ilha/router/oxlint` is a JavaScript Oxlint plugin. The current rule set still names the previous primitive API (`state`, `ilha()`, `hydratable`). Do not enable it against the `atom` / `when` / `renderToString` API until those rules are updated.

Use TypeScript and the guides in this docs set for call-order and event-prop conventions in the meantime.
