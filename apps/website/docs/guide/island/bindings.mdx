---
title: Bind state
description: Two-way bindings between form elements and signals, including nested-field select, radio and checkbox groups, and element references.
---

Inside JSX, use `bind:property={signal}` to create two-way bindings between form elements and signals. When the signal changes, the element updates. When the user interacts, the signal updates.

Use `bind:*` for synchronization and lowercase events for custom logic. You can put both on the same element:

```tsx twoslash
import { ilha, state } from "ilha";

const validate = () => {};

const Name = ilha(() => {
  const name = state("Ada");
  return (
    <div>
      <input bind:value={name} onchange={() => validate()} />
      <p>Hello, {name()}</p>
    </div>
  );
});
```

## Supported bindings

| Binding        | Element                                           | Bound property      | Trigger event |
| -------------- | ------------------------------------------------- | ------------------- | ------------- |
| `bind:value`   | `<input>`, `<textarea>`, `<select>`               | `value`             | `input`       |
| `bind:checked` | `<input type="checkbox">`                         | `checked`           | `change`      |
| `bind:group`   | `<input type="radio">`, `<input type="checkbox">` | `checked` / `value` | `change`      |
| `bind:open`    | `<details>`                                       | `open`              | `toggle`      |
| `bind:files`   | `<input type="file">`                             | `files`             | `change`      |
| `bind:this`    | Any element                                       | element reference   | —             |

The element type is detected at runtime — no configuration needed.

## Radio and checkbox groups

```tsx twoslash
import { ilha, state } from "ilha";

const Plan = ilha(() => {
  const plan = state("pro");
  return (
    <>
      <input
        type="radio"
        name="plan"
        value="free"
        bind:group={plan}
      />
      <input
        type="radio"
        name="plan"
        value="pro"
        bind:group={plan}
      />
    </>
  );
});
```

## Nested fields with `.select()`

Bind to a nested slice of an object or array with `.select()` instead of replacing the whole value on every keystroke. Both a selector function and a property path work:

```tsx twoslash
import { ilha, state } from "ilha";

const Profile = ilha(() => {
  const user = state({ name: "Ada", role: "dev" });
  return <input bind:value={user.select((u) => u.name)} />;
});
```

In a list, select the item field inside `.map()`:

```tsx twoslash
import { ilha, state } from "ilha";

const Todos = ilha(() => {
  const todos = state([
    { text: "Learn ilha", completed: false },
  ]);
  return (
    <ul>
      {todos().map((todo, index) => (
        <li key={todo.text}>
          <input
            type="checkbox"
            bind:checked={todos.select(
              (t) => t[index].completed,
            )}
          />
          {todo.text}
        </li>
      ))}
    </ul>
  );
});
```

Pass the property path directly as an alternative to a selector function:

```tsx twoslash
import { ilha, state } from "ilha";

const Profile = ilha(() => {
  const user = state({ profile: { name: "Ada" } });
  return <input bind:value={user.select("profile", "name")} />;
});
```

The selector (or path) must traverse nested state. Writes update only that path — siblings stay intact.

## Element references

```tsx twoslash
import { ilha, state } from "ilha";

const Focus = ilha(() => {
  const ref = state(null as HTMLInputElement | null);
  return <input bind:this={ref} />;
});
```

## Number coercion

`bind:value` and radio-group `bind:group` coerce the DOM string value back to a number when the bound signal currently holds a number. For typed number or date reads, use the native event properties instead — `valueAsNumber` and `valueAsDate` are element properties, not binding kinds:

```tsx twoslash
import { ilha, state } from "ilha";

const Age = ilha(() => {
  const age = state(0);
  return (
    <input
      type="number"
      value={age()}
      oninput={(event) => {
        const el = event.currentTarget as HTMLInputElement;
        age(
          Number.isNaN(el.valueAsNumber) ? 0 : el.valueAsNumber,
        );
      }}
    />
  );
});
```

## Native event modifiers

Lowercase event props keep their modifiers: `:once`, `:capture`, `:passive`, and `:abortable`:

```tsx twoslash
import { ilha, state } from "ilha";

const search = (text: string, signal: AbortSignal) => {
  void text;
  void signal;
};

const App = ilha(() => {
  const query = state("");
  return (
    <>
      <button onclick:once={() => console.log("run once")}>
        Run once
      </button>
      <input
        oninput:abortable={(event, { signal }) =>
          search(event.currentTarget.value, signal)
        }
      />
      {query()}
    </>
  );
});
```

## Component contracts

A custom component must relay `bind:*` props to its controller — ilha only wires bindings placed directly on native elements rendered by that island. Keep user-input writes and programmatic signal writes separate so a controlled prop update does not masquerade as user input.
