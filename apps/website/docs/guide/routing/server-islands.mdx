---
title: Server islands
description: Render selected components on the server with Oxide, frames, and oxidejs actions.
---

Use [Oxide](https://npmjs.com/package/oxidejs) when a component must close over server data. You keep the SPA authoring model. Files named `*.server.tsx` never ship their render function to the browser.

```ts twoslash
import pages from "@ilha/router/vite";
import oxide from "oxidejs/vite";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    oxide({ middleware: ["@ilha/router/ssr"] }),
    pages(),
  ],
});
```

The middleware owns:

| Endpoint             | Purpose                      |
| -------------------- | ---------------------------- |
| `POST /__ilha/frame` | Render a server island again |

There is no page loader endpoint. Fetch inside an async component, or yield from a streaming action.

## One island on the server

Put the component in `*.server.ts(x)`:

```tsx
import * as Stream from "effect/Stream";
import { action } from "oxidejs";

export const deleteTask = action(async (id: string) => {
  await db.tasks.delete(id);
});

export const getTasks = action(async function* () {
  yield await db.tasks.list();
});

export const TaskList = async function TaskList() {
  return Stream.map(
    Stream.fromAsyncIterable(getTasks(), (error: unknown) =>
      error instanceof Error ? error : new Error(String(error)),
    ),
    (list: { id: string; text: string }[]) => (
      <ul>
        {list.map((task) => (
          <li key={task.id}>
            {task.text}
            <button
              type="button"
              onclick={() => deleteTask(task.id)}
            >
              Remove
            </button>
          </li>
        ))}
      </ul>
    ),
  );
};
```

Import it from a regular page:

```tsx
import { TaskList } from "$lib/tasks.server";

export default function Home() {
  return <TaskList />;
}
```

The plugin replaces the server module with a client proxy. The proxy posts `/__ilha/frame`, morphs the HTML, and reconnects events.

Mark RPC functions with `action` from `oxidejs`. Event closures that call those actions serialize into the frame HTML.

Subscribe with `Stream.fromAsyncIterable(getTasks())` so the scanner wires a live stream. Each yield refetches the frame.

## Whole route on the server

Name the page `foo.server.tsx`. Export a default component. The client still mounts a proxy and pulls the first frame.

## Auth

Frames are deny-by-default in production. For a public demo:

```ts twoslash
import { setFrameAuth } from "@ilha/router/ssr";

setFrameAuth({ defaultAction: "open" });
```

Install `setFrameGuard()` when islands serve private data. See [Middleware and security](/guide/routing/middleware-and-security).
