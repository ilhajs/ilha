title: Router overview
description: File routes, SPA navigation, and optional Oxide SSR for ilha apps.
---

`@ilha/router` matches URLs to components. It is a separate package from `ilha`. Add it when you need more than one page.

Every route is a component. The router matches the URL and mounts the page. Read the current route with `useRoute()`, `head()`, and `isActive()`.

## Install

```package-install
@ilha/router
```

## Import paths

| Import path | Use it for |
| --- | --- |
| `@ilha/router` | Runtime router, navigation, `head`, route hooks |
| `@ilha/router/vite` | Vite file-system routing plugin |
| `@ilha/router/rsbuild` | Rsbuild file-system routing plugin |
| `@ilha/router/server-island` | Client proxies for `*.server` modules (generated) |
| `@ilha/router/ssr` | `POST /__ilha/frame` middleware and frame guards |

There is no loader API. Fetch in an async page, or stream from a server module.

## Quick start

### Client SPA

```tsx twoslash
import { router } from "@ilha/router";

const HomePage = () => <p>home</p>;
const AboutPage = () => <p>about</p>;
const NotFound = () => <p>not found</p>;

router()
  .route("/", HomePage)
  .route("/about", AboutPage)
  .route("/**", NotFound)
  .mount("#app");
```

### File-system routes

```ts twoslash
import { pages } from "@ilha/router/vite";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [pages()],
});
```

Put pages in `src/pages/`. See [File-system routing](/guide/routing/file-system-routing).

### Server HTML

Add Oxide and the SSR middleware when pages or islands run on the server:

```ts twoslash
import pages from "@ilha/router/vite";
import oxide from "oxidejs/vite";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [oxide({ middleware: ["@ilha/router/ssr"] }), pages()],
});
```

See [Server islands](/guide/routing/server-islands).
