---
title: File-system routing
description: Generate routes from src/pages/ with the pages plugin.
---

The pages plugin scans `src/pages/`, wraps layouts, and generates a router. Pick the entry for your toolchain:

| Tool    | Import                 |
| ------- | ---------------------- |
| Vite    | `@ilha/router/vite`    |
| Rsbuild | `@ilha/router/rsbuild` |

## Setup

```ts twoslash
import pages from "@ilha/router/vite";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [pages()],
});
```

## File names

| File                  | URL            |
| --------------------- | -------------- |
| `pages/index.tsx`     | `/`            |
| `pages/about.tsx`     | `/about`       |
| `pages/user/[id].tsx` | `/user/:id`    |
| `pages/[...slug].tsx` | `/**:slug`     |
| `pages/+layout.tsx`   | wraps children |
| `pages/+error.tsx`    | error boundary |

`foo.server.tsx` uses the same URL as `foo.tsx` and renders on the server. See [Server islands](/guide/routing/server-islands).

## Page module

Export a default component:

```tsx
import { head } from "@ilha/router";

export default function Home() {
  head({ title: "Home" });
  return <h1>Home</h1>;
}
```

## Layout

```tsx twoslash
import type { View } from "ilha";

export default function Layout({ children }: { children?: View }) {
  return (
    <div>
      <nav>
        <a href="/">Home</a>
      </nav>
      <main>{children}</main>
    </div>
  );
}
```

## Client entry

```ts
import { pageRouter } from "ilha:pages/client";

pageRouter.mount("#app");
```

Hydrate when the host already has SSR markup:

```ts
pageRouter.mount("#app", { hydrate: true });
```
