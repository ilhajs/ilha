Use the `action()` primitive to define a reusable operation that belongs to the island. Call it from a lowercase native event prop such as `onclick`:

```tsx twoslash
import { ilha, state, action } from "ilha";

const Counter = ilha(() => {
  const count = state(0);
  const increase = action(() => {
    count((value) => value + 1);
  });

  return <button onclick={increase}>Increase</button>;
});
```

The action owns the state update. The native handler connects that operation to one rendered element. You can call the same action from another event or effect without duplicating the update logic.
