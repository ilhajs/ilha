Derived properties let you compute values from state automatically, recalculating only when their dependencies change. Use `derived()` to keep complex logic out of your templates.

```ts twoslash
import { state, derived } from "ilha";

const count = state(0);
const doubled = derived(() => count() * 2);
```

The callback receives a lifecycle `signal` for async work. The result is read with `doubled()` — the same call syntax as state.

`derived()` also accepts an async function, making it suitable for data fetching. Async derived values expose `loading`, `value`, and `error` on the accessor — built-in async state without reaching for SWR or TanStack Query.
