Use this page as a map of the public `ilha` API. Start with [Introduction](/guide/getting-started/introduction) if you are building your first component.

## Component

A component is a function, async function, or generator that returns a view.

```tsx twoslash
import { atom } from "ilha";

const Status = () => <p>Ready</p>;

const Greeting = ({ name }: { name: string }) => <p>Hello, {name}</p>;

const Counter = () => {
  const count = atom(0);
  return (
    <button type="button" onclick={() => count.update((n) => n + 1)}>
      {count}
    </button>
  );
};
```

Nested functions share the parent fiber. `mount` / `renderToString` on a function makes it a root.

## Element props

Every element accepts `key` and `ref` with no extra types. `key` reuses DOM nodes in lists; `ref` receives the live node on mount and `null` on unmount. Components accept `key` through `JSX.IntrinsicAttributes` — never add it to your own props. Disclosure and dialog events (`ontoggle`, `onbeforetoggle`, `onclose`, `oncancel`) type `currentTarget` to the element.

`data-morph-preserve="a b"` keeps the named live attributes across rerenders; the `children` token keeps the element's live children. A user-opened `<details>` or `<dialog>` keeps `open` unless the render sets it explicitly. See [Templating](/guide/ui/templating).

Paint Effect [`Stream`](https://www.effect.website/docs/v4/api/effect/Stream) values with `yield Stream.map(...)` — see [Streams](/guide/ui/streams).

`define` lives at `ilha/define` — see [Custom elements](/guide/ui/custom-elements).

## atom

| Call               | Meaning                |
| ------------------ | ---------------------- |
| `atom(value)`      | Writable atom          |
| `atom.lazy(fn)`    | Run `fn` once on init  |
| `atom(effectAtom)` | Wrap an Effect atom    |
| `count()`          | Read                   |
| `count.set(v)`     | Replace                |
| `count.update(fn)` | Patch                  |
| `count.atom`       | Underlying Effect atom |

Derived values use Effect's `Atom.map` or `Atom.transform` — pass `handle.atom`, then wrap in `atom()`:

```tsx twoslash
import * as Atom from "effect/reactivity/Atom";
import { atom } from "ilha";

const items = atom([1, 2]);
const sum = atom(
  Atom.map(items.atom, (list) => list.reduce((total, n) => total + n, 0))
);
```

### Atoms from Effect

The initializer also accepts an Effect atom, an Effect, or a Stream:

```tsx twoslash
import * as Effect from "effect/Effect";
import { atom } from "ilha";

declare const effect: Effect.Effect<string>;
// ---cut---
const status = atom(effect);
```

The value of an Effect-backed atom is an Effect `AsyncResult`. During paint, waiting results keep the previous view, failures render the error text, and successes render the value. Use this to hold async data in atoms; for streams of views, prefer [Streams](/guide/ui/streams).

## watch

Order-based primitive — call at the top level of a component. `watch(source, fn)` runs `fn` when `source` changes and once on mount. Accepts an atom handle, `handle.atom`, or a `Stream`. `watch.once(fn)` runs `fn` once on mount; return a function to clean up on unmount.

Both forms pass `{ signal, onCleanup }`: the signal aborts when a run goes stale or the component unmounts, and callbacks may be async with a promised cleanup.

## when

Generator instruction — use with `yield*` inside a generator component. Prefer yielding a `Stream` of views directly when you do not need per-emission interruption.

- `when(stream, body)` — run generator `body` for each value; a new value interrupts the previous body. SSR takes the first value.

Stream views (`yield Stream.map(...)`) also take one value on SSR. Side effects and user-gated flows use Effect (`Stream.runForEach`, `Deferred`) — see [Streams](/guide/ui/streams).

## renderToString

```ts
await renderToString(component, {
  snapshot?: boolean;      // embed atom values for hydration (default true)
  markers?: boolean;       // wrap in <div data-ilha> (default true)
  timeout?: number;        // serialize after this many ms even if busy
  captureActions?: boolean; // probe handlers for server-action calls
});
```

Waits until in-flight work is idle, then serializes. `when` and Stream views take one value.

## mount

```ts
const unmount = mount(element, component, {
  hydrate?: boolean;              // restore snapshots from existing markup
  onError?: (error: Error) => void; // component failure hook
});
```

`onError` receives a failing root component and a nested component no `ErrorBoundary` caught, before the error view paints.

## ilha/renderer

`createRenderer(ops)` paints components into a host that is not a DOM: a native toolkit, a canvas scene graph, a test tree. You supply `PaintOps`; atoms, generators, streams, contexts, keyed components, and error boundaries behave as they do under `mount()`.

```ts
import { createRenderer } from "ilha/renderer";
import type { PaintOps } from "ilha/renderer";

const renderer = createRenderer(ops);
const { unmount, ready, runtime } = renderer.mount(root, App, {
  onError?: (error: Error) => void;         // component failure hook
  onRuntime?: (runtime: IlhaRuntime) => void; // runs before the root component
});
```

Every paint materializes fresh host nodes and hands the complete child list of the painted root to `ops.placeChildren(root, nodes)`. Your host decides what to keep.

| Op | Role |
| --- | --- |
| `createElement`, `createText` | Build a host node |
| `createRaw(html, parent)` | Nodes for an `unsafe()` view |
| `createSlotHost(slotId)` | Host of a component, atom, or stream hole |
| `asRoot`, `asNode`, `asElement` | View a host as a fiber root, a placeable node, or an element |
| `placeChildren(root, nodes)` | Make a root's children exactly `nodes` |
| `appendRoot(root, node)` | Append one node. Only `painter.insert` calls it, never `mount()` |
| `reuseNode(host)` | Node to place for a hole that survived the repaint |
| `setProp(el, key, value)` | Optional. Return `true` to claim a prop with its original value |
| `setStyle`, `setFormControl` | Default handling for `style` and `value` / `checked` |
| `bindEvents(el, props, fiber)` | Bind event props; call the exported `bindEvents` to reuse Ilha's |
| `disconnect(el)` | A hole's host left the tree for good |
| `committed(el)` | The element a rendered element ended up as, for refs |

Every op except `setProp` is required.

Without `setProp`, a prop reaches the host as a string attribute and a `style` object as CSS text. Implement it to receive objects as written.

`onRuntime` hands you the mount's runtime before any component runs. Every fiber of the mount carries it, so `getFiber().runtime` identifies the mount from inside a component.
