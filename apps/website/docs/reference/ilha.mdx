Use this page as a map of the public `ilha` API. Start with [Introduction](/guide/getting-started/introduction) if you are building your first component.

## Component

A component is a function, async function, or generator that returns a view.

```tsx twoslash
import { atom } from "ilha";

const Status = () => <p>Ready</p>;

const Greeting = ({ name }: { name: string }) => (
  <p>Hello, {name}</p>
);

const Counter = () => {
  const count = atom(0);
  return (
    <button
      type="button"
      onclick={() => count.update((n: number) => n + 1)}
    >
      {count}
    </button>
  );
};
```

## Named exports

| Export              | Purpose                                  | Learn more                         |
| ------------------- | ---------------------------------------- | ---------------------------------- |
| `atom(init)`        | Writable or computed reactive value      | [State](/guide/ui/state)           |
| `when(stream, fn)`  | Render a generator body per Stream value | [Streams](/guide/ui/streams)       |
| `watch(source, fn)` | Side effect on atom or Stream            | [Streams](/guide/ui/streams)       |
| `wait(body)`        | Pause a generator until `done(value)`    | [Streams](/guide/ui/streams)       |
| `h` / `Fragment`    | JSX factory                              | [Templating](/guide/ui/templating) |
| `mount`             | Activate a component in the DOM          | [Render](/guide/ui/render)         |
| `renderToString`    | Serialize a component to HTML            | [Render](/guide/ui/render)         |

`define` lives at `ilha/define`.

## atom

| Call               | Meaning                |
| ------------------ | ---------------------- |
| `atom(value)`      | Writable atom          |
| `atom(() => expr)` | Computed atom          |
| `count()`          | Read                   |
| `count.set(v)`     | Replace                |
| `count.update(fn)` | Patch                  |
| `count.atom`       | Underlying Effect atom |
