See [Router overview](/guide/routing/overview) for a guided tour.

## `@ilha/router`

| Export                     | Purpose                 |
| -------------------------- | ----------------------- |
| `router()`                 | Build and mount a SPA   |
| `navigate` / `isActive`    | Programmatic navigation |
| `useRoute`                 | Path, params, search    |
| `head`                     | Document title and tags |
| `wrapLayout` / `wrapError` | Used by generated code  |

## `@ilha/router/vite` and `/rsbuild`

`pages(options?)` — file-system routing plugin. Default dir `src/pages`.

## `@ilha/router/ssr`

Production middleware for `POST /__ilha/frame`.

| Export          | Purpose                        |
| --------------- | ------------------------------ |
| `setFrameAuth`  | `open` / `deny`, origins, CSRF |
| `setFrameGuard` | Per-request allow/deny         |

## `@ilha/router/server-island`

Generated client proxies. You do not import this in app code.

There is no loader helper. Fetch in the page, or stream from a `*.server` module.
