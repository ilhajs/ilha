See [Astro](/guide/astro) for setup.

Default export: `ilha(options?)` Astro integration.

| Option    | Meaning                                     |
| --------- | ------------------------------------------- |
| `include` | Glob or list of globs this renderer accepts |
| `exclude` | Glob or list of globs this renderer skips   |

Named exports: `getRenderer()`, `getViteConfig(options)`.

The server entry calls `renderToString`. The client entry calls `mount(..., { hydrate })`.
